# One alternate-host profiling probe

Added after the completed Blackwell run, before any alternate-host samples.
The secure server host denies hardware counters (ERR_NVGPUCTRPERM, even though
query exits zero). Its phase/event evidence and all failures are preserved.

Close that GPU and the unreachable client after remote round-trip backup checks.
Try at most one Community Cloud RTX 4090 at the live advertised $0.34/hour, with
a 30-minute hard rental stop guard. First run only NVML/inventory and profiler
metric discovery. Do not change driver/module settings, privileges, clocks or
power. If counters are denied, preserve that result, back up and delete the
probe without compiling or benchmarking. No automatic host-shopping loop.

If permitted, execute the same correctness-checked phase study, compiled for
Ada sm_89, with 40 repeats/window fixed before samples so windows exceed 100 ms.
Hardware counters on that board are a separate cohort; never substitute them
for a Blackwell measurement. Counter activity still cannot be interpreted as
additive photonic-removable wall time. All kernel sources remain private.
